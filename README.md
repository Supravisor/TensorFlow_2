# TensorFlow 2.0
This is a TensorFlow 2.0 console for learning algorithms.
* linear regression
* classification
* hidden Markov model

## Key feature
Single-click buttons for instantly creating syntactically correct code.

## Usage instructions
Click the desired button and the TensorFlow code will appear in the textbox element for linear regression and classification.

I also created Jupyter notebooks using the code. This is no code console for the hidden Markov model.

Here is the live link to [TensorFlow 2](https://supravisor.github.io/TensorFlow_2/).
